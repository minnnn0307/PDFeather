# PDFeather

오프라인 Windows 10/11 x64 PDF 리더. Python을 설치하지 않은 PC에서도 설치본 실행이 가능합니다. 문서 열기·표시·복사·캡처·인쇄는 인터넷 없이 동작합니다. 업데이트 확인을 켜면 GitHub Releases의 공개 버전 정보만 조회하며, 사용자가 업데이트 설치 버튼을 누르면 설치 파일을 내려받아 크기와 SHA-256을 검증한 뒤 설치하고 재실행합니다.

- 설치 시 PDF의 연결 프로그램 후보로 등록합니다. 기본 PDF 앱은 변경하지 않으므로 더블클릭으로 사용하려면 Windows 기본 앱 또는 탐색기 연결 프로그램에서 PDFeather를 선택하세요.
- 일반 포인터 / 손 도구 / 텍스트 선택을 나란히 배치했습니다. 일반 포인터는 선택·캡처 없이 보고, 손 도구는 드래그한 만큼 화면을 이동합니다.
- 설정 아이콘을 8개 톱니의 일반적인 기어 모양으로 변경했습니다. 하단 보기 선택은 페이지 배치 아이콘·선택 표시가 있는 메뉴로 바꿨습니다.
- 개발·설치 EXE 모두에서 두 프로세스 파일 전달, 중복 탭 억제, 한글·공백 경로, 강제 종료 후 복구를 검사합니다.

## 1.3.0 변경 · 버전 및 업데이트 정책

- 명칭은 앱 제목, 실행 파일·설치 파일의 제품명/설명, 설치 목록에서 `PDFeather`로 통일했습니다. 버전은 프로그램명에 붙이지 않고 정보 페이지와 버전 속성에 별도로 표시합니다.
- 게시자는 한국어 UI에서 `조민혁`, 영어 UI에서 `Minhyeok Cho`입니다. 실행 파일은 한국어·영어 회사 정보 테이블을 포함하고, 설치 목록은 Windows UI 언어에 따라 게시자를 설정합니다. Inno Setup 설치 파일 자체의 고정 회사 속성은 영어명이며 설치되는 프로그램의 게시자는 언어별로 표시됩니다.
- 버전은 SemVer 2.0.0을 따릅니다. 기능 추가는 MINOR, 수정은 PATCH, 호환성을 깨는 변경은 MAJOR를 올립니다. `app_meta.py`를 단일 기준으로 사용하고 `python scripts/build_metadata.py`로 Windows/설치 메타데이터를 생성합니다.
- 설정 → 일반 → 업데이트에서 자동 확인을 켜거나 끌 수 있습니다. 기본값은 켜짐이며 하루 한 번 백그라운드에서 확인합니다. 인터넷이 없거나 확인에 실패해도 문서 기능을 방해하지 않습니다. 설정 → 정보 → 지금 확인에서 수동으로 확인할 수 있습니다.
- 정식 버전의 설치 EXE가 공개된 경우에만 새 버전을 알립니다. 베타·초안·구버전은 알리지 않습니다. 알림을 닫으면 같은 버전은 다시 자동 표시하지 않으며, 수동 확인은 계속 가능합니다.
- 업데이트 확인은 버전이 포함된 User-Agent와 공개 릴리스 정보 요청만 전송합니다. PDF 내용·파일명·문서 경로는 전송하지 않습니다. 확인은 비동기이며 8초 내에 종료합니다.
- 기존 1.2.0에는 확인 기능이 없으므로 1.3.0을 한 번 수동 설치해야 이후 알림을 받을 수 있습니다.
- 설치 정보의 게시자와 Windows 보안 경고의 서명자는 별개입니다. 이 프로젝트에는 코드 서명 인증서가 포함되지 않으며, 보안 경고에 확인된 게시자로 표시하려면 실제 인증서로 서명해야 합니다.

## 텍스트 복사 · 문서 탭 · 다중캡처

- **텍스트 선택**: 상단 T 아이콘에서 글자를 드래그하고 Ctrl+C 또는 우클릭 → 선택한 텍스트 복사. 여러 페이지에 걸친 선택과 드래그 중 가장자리 자동 스크롤을 지원합니다. 스캔 문서에는 OCR이 필요합니다.
- **영역 캡처**: 상단 캡처 아이콘을 선택하고 영역을 드래그하면 이미지가 즉시 클립보드에 복사됩니다. 선택·검색 강조, 도구막대 등 UI는 포함하지 않습니다.
- **다중캡처**: 상단 다중캡처 아이콘 → 첫 영역 드래그 → 스크롤이나 페이지·탭 이동 → 다음 영역 드래그 → **이어붙여 복사**. 캡처한 순서대로 위에서 아래로 연결합니다. 폭이 다른 조각은 변형 없이 가운데 정렬하고 남는 폭은 흰색으로 채웁니다. 미리보기 / 마지막 취소 / 초기화를 제공합니다. Ctrl+C도 합친 이미지를 복사합니다.
- 다중캡처 목록은 문서 탭을 바꾸거나 원본 탭을 닫아도 유지됩니다. 조각은 임시 PNG로 보관해 평상시 메모리 부담을 낮추며 프로그램 종료 시 제거합니다. 합친 이미지는 최대 1,600만 픽셀·한 변 30,000픽셀입니다. 제한을 넘는 추가는 기존 캡처를 유지한 채 안내합니다.
- 여러 PDF를 선택해 열거나 끌어 놓으면 문서별 탭으로 열립니다. 같은 경로는 기존 탭을 활성화합니다. 탭 이동·닫기, Ctrl+W, Ctrl+Tab / Ctrl+Shift+Tab을 지원합니다.
- 탭마다 페이지·배율·보기·스크롤·검색·텍스트 선택 상태를 보관합니다. 비활성 탭의 렌더링 캐시는 즉시 비우며 활성 탭만 렌더링합니다. 모든 탭의 화면 캐시 합계는 64 MiB 이내입니다. 열린 PDF 자체와 캡처·클립보드 메모리는 별도입니다.

- PDF 글자를 크게 키운 문서·깃펜 아이콘으로 변경했습니다. 제목 표시줄 로고는 글자 줄 높이에 맞추고 고해상도 디스플레이를 지원합니다. 설치 프로그램은 버전별 ICO 경로를 지정해 바로가기의 이전 아이콘 캐시를 피합니다.

## 기능

- Ctrl+마우스 휠: 마우스 포인터 기준 확대/축소 (10~500%), 하단 오른쪽 배율 입력과 +/- 버튼
- 쪽 맞추기 / 너비 맞추기, 창 크기 변경 시 맞춤 유지
- 통합 제목 표시줄: 최소화 / 최대화·복원 / 종료, 제목줄 이동·더블클릭, 가장자리 크기 조절
- 아이콘 도구막대와 도움말(F1), 하단 왼쪽 안내 문구 제거
- 단일 / 단일 스크롤 / 2페이지 / 2페이지 스크롤. 문서 외곽 여백·테두리 제거, 연속 보기에는 얇은 페이지 경계선
- 단일 / 2페이지 보기에서 맨 아래에서 휠을 더 내리면 다음 페이지, 맨 위에서 올리면 이전 페이지
- 하단 가운데 현재 페이지 / 전체 페이지 및 번호 입력 이동
- 왼쪽 스크롤 썸네일, 클릭 이동, 보이는 썸네일부터 생성. 하단 중앙의 반투명 배경 페이지 번호
- Ctrl+F 텍스트 찾기, 검색 결과 강조, Enter/F3 다음 결과, Shift+Enter/Shift+F3 이전 결과, Esc 닫기
- PDF 메타데이터, 파일 크기, 페이지 크기 확인
- 암호 PDF 열기, 드래그 앤 드롭, Ctrl+O, Ctrl+P
- 별도 프로세스에서 프린터 조회·인쇄·미리보기 생성. 선택한 용지 한 면씩 미리보기와 이전/다음 이동, 작업 중단
- 인쇄 미리보기: 단면 / 양면 긴 쪽·짧은 쪽, 가로 / 세로, A4 / A3 / Letter / Legal
- 한 면에 1 / 2 / 4 / 6 / 9 / 16페이지, 페이지 범위, 매수
- 용지에 맞춤 / 실제 크기 / 10~400% 사용자 인쇄 배율

화면 캐시는 64 MiB로 제한합니다. 타일은 768×768 픽셀(경계 렌더링용 여유 영역 별도)이며, 페이지 이미지 모드의 개별 비트맵은 1,600만 픽셀 이하입니다. PDF 자체와 Qt 런타임 메모리는 별도입니다. Qt/Python 런타임이 포함되므로 설치 용량이 몇 MB 수준인 초소형 네이티브 앱은 아닙니다. 실제 크기와 시작 시간은 Windows 빌드 후 측정해야 합니다. 무거운 문서는 렌더링 중 UI가 잠시 멈출 수 있습니다. 인쇄는 최대 300dpi의 래스터 출력이며 텍스트 벡터를 보존하지 않습니다.

```powershell

python main.py

```

## GitHub 연결 및 설치 EXE 만들기

1. GitHub에서 빈 저장소를 생성합니다. 이 ZIP을 풀고 README.md와 .github 폴더가 있는 폴더에서 아래를 실행합니다.

```powershell
git init
git add .
git commit -m "Initial offline PDF reader"
git branch -M main
git remote add origin https://github.com/minnnn0307/PDFeather.git
git push -u origin main
```

2. GitHub Actions의 **Windows installer** 빌드가 완료되면 **Artifacts → PDFeather-1.10.1-Windows-x64**에서 압축 파일을 내려받습니다. `release/PDFeather-1.10.1-Setup.exe`가 설치 프로그램입니다. `dist/PDFeather` 폴더 전체는 무설치 실행용입니다.
3. 버전 배포: `app_meta.VERSION`을 올리고 RELEASE_NOTES.md를 갱신한 뒤 main에 push합니다. Windows 검사·설치 검증이 통과하면 `v<VERSION>` GitHub Release와 설치 EXE가 자동 게시됩니다. 이미 배포된 버전의 코드를 바꿀 때는 반드시 버전을 올립니다. 태그로 실행할 경우 태그는 `app_meta.VERSION`과 일치해야 합니다.

서명 인증서는 포함되어 있지 않습니다. 서명 없는 설치 EXE에는 Windows 보안 경고가 표시될 수 있습니다. GitHub 저장소: https://github.com/minnnn0307/PDFeather

## 검증 상태와 제한

자동 검사: 실제 다중 프로세스 전달·충돌 복구, 포인터·손 드래그·상단 통합 탭, 모달 창 대기, 보기 메뉴, SemVer 우선순위·안정 릴리스/자산 필터, 업데이트 실패·시간 제한·취소·하루 주기·사용자 설정, 양언어 제품 메타데이터, 실제 드래그·Ctrl+C 텍스트 복사, 스크롤 후 추가 드래그·다중캡처 이미지 클립보드, 합성 순서·폭 패딩·취소·크기 제한, 여러 탭의 보기·검색·선택 복원과 캐시 해제, 타일 결과와 고해상도 기준 이미지의 픽셀 일치, 500% 확대·2배 모니터 배율에서 부분 렌더링과 캐시 제한, 인쇄 배율 기준·입력 활성화, 페이지 범위 오류, N-up 배치 계산, 실제 5페이지 PDF 열기/렌더링, 네 가지 보기 모드, 포인터 기준 확대 좌표 보존, 페이지 끝 휠 넘김, 텍스트 검색 결과, 2-up 출력 PDF의 3장 생성, 인쇄 미리보기 중 이벤트 루프 응답, 출력 PDF의 실제 여백, 테마 전환과 설정 영속성, 단일·2페이지 중앙 정렬. Linux와 GitHub Actions의 Windows offscreen Qt 환경에서 수행합니다. 빌드된 Windows EXE 자체에서도 별도 프로세스 미리보기가 생성되는지 검사합니다. Windows 설치/제거, 프린터 드라이버별 양면·매수·용지 적용, 큰 문서 성능은 실제 Windows 장치에서 추가 확인해야 합니다. 양면 기능은 드라이버와 프린터 지원에 따릅니다. 미리보기는 레이아웃을 보여주며 프린터의 물리적 양면 동작은 재현하지 않습니다.

검색은 PDF 텍스트 레이어를 대상으로 하며 OCR은 포함하지 않습니다. 검색 결과는 최대 10,000개입니다. 프린터 조회가 오래 걸리면 제한 시간 후 미리보기로 이동하며 다시 조회할 수 있습니다. 인쇄 중단 전에 Windows 대기열로 전송된 작업은 대기열에서 취소해야 합니다.

설정은 Windows 사용자별로 저장됩니다. 테마는 앱 UI에 적용하며 PDF 문서의 원래 색은 유지합니다. 인쇄 미리보기의 점선은 출력 영역 안내이며 출력물에는 포함되지 않습니다. 여백 0 mm는 프린터의 무테 인쇄 지원이 필요하고, 하드웨어 인쇄 불가 영역 안의 내용은 잘릴 수 있습니다.

바탕화면 바로가기는 설치 시 “Create a desktop shortcut”을 선택하면 갱신됩니다. 직접 만든 바로가기나 작업 표시줄에 고정한 아이콘은 Windows가 이전 연결을 유지할 수 있으므로 새 설치본을 다시 연결해야 할 수 있습니다.
